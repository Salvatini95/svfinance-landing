## Sobre

Vitrine de entrada para os produtos SV Finance. HTML/CSS/JS puro — sem framework, sem build step.

## Estrutura

```
svfinance-landing/
├── index.html      # Página única
├── css/style.css   # Estilos
├── js/main.js      # Toggle planos, carrossel, scroll reveal
└── img/            # Fotos fundadores + posts Instagram
```

## Desenvolvimento local

Abra `index.html` no browser ou use Live Server (VS Code).

## Deploy

Push na `main` → Vercel publica automaticamente (sem build).

## Seções

Hero com logo animado · Dashboard SVG · Cards 3D parallax · Planos com toggle mensal/anual · Fundadores · Carrossel Instagram · Responsivo (mobile XS → 4K)
